# Documentation

This folder holds project documentation: FAQs, design notes, and implementation plans for RoRoOS.

- `FAQ.md` — Frequently asked questions and quick answers for contributors and users.
- `PLANS.md` — Short- and mid-term project plans and roadmap items.

Guidelines:
- Keep FAQs concise and searchable.
- Link to issues/PRs from plan items when implemented.
- Prefer markdown headings and short bullet lists.

To add or update docs:

```bash
# edit or add files under documentation/
git add documentation/<file>.md
git commit -m "Update documentation: <topic>"
git push
```
